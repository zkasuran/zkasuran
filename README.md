error mitigation and a cloud provider backend.

**MiniMaxathon, Multimodality track winner.** [Overhear](https://github.com/zkasuran/overhear)
turns a topic into a two-host audio episode with an original theme song. One model family
writes the script, a second voices it, a third scores it.

## 🔭 Selected work

| Project | What it does |
| :--- | :--- |
| **[vibe-terminal](https://github.com/zkasuran/vibe-terminal)** | Route any model through any CLI. A cost-routing layer for terminal coding agents. |
| **[TinyLang](https://github.com/zkasuran/TinyLang)** | A language toolchain in TypeScript: interpreter, 63-opcode bytecode VM, WebAssembly target, debugger, browser IDE. 1003 tests, byte-identical output across backends. |
| **[testrazor](https://github.com/zkasuran/testrazor)** | Change-aware, flake-aware CI test gate. |
